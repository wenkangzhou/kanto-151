# 使用场景与设计约定

- 主要使用者：5 岁、识字不多的孩子，主要设备是 iPad；优先适配横竖屏与触控。
- 家长主要使用 iPhone，偶尔在孩子的 iPad 上通过 PIN 操作奖励。保持单家庭、多设备模式。
- 孩子端先用图形、图片、操作反馈表达含义，文字用于陪看说明。状态不能只靠颜色区分。
- 图鉴状态保持统一形状：可遇见为精灵球，未开放为锁，已收集为勾，可进化为星光。可遇见包含普通捕捉、进化及传说条件已开放，不表示所有目标都能靠普通捕捉码获得。
- 属性教学明确区分招式与宝可梦本身，箭头指向受招式影响的一方。单属性示意与真实双属性例子分别计算；例子只展示已经收集的伙伴，保留未发现的惊喜。
- 种族值与较长说明放在次要位置，供家长陪看。新功能优先使用大按钮、明显选中态和至少 44px 的触控区域。
- 沉浸感沿用精灵球 loading、相遇与进化仪式；不覆盖用户已有视觉修改。日常操作轻快，长动画可跳过，遵循减少动态效果设置；音频必须可静音。

- 背景音乐仅供大屏 iPad / 桌面主动开启，手机横竖屏均不加载。默认关闭，后台或窄屏时停止；共享布局保留站内连续播放。
