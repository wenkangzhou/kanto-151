# 长期使用可靠性检查（2026-10-22）

本轮优先处理会话同步及旧响应覆盖。没有执行生产数据库写入、迁移、备份恢复或真实多设备压测。

## 已完成

- 后台刷新合并：窗口聚焦、网络恢复、可见状态变化同时发生时，共享同一代读取请求。
- 写入后的刷新与手动重试强制开始新一代读取，不复用写入前的旧请求。
- 保存小队或招式前废弃旧读取；失效设备、家长锁定、组件卸载后，旧结果和旧错误不能再覆盖状态。
- 保存小队或招式后后台重新校准完整快照，包括未打开的精灵球。无需让保存按钮继续等待整个快照。
- 页面可见且在线时每 60 秒检查一次其他设备更新；后台或离线不定时请求，返回前台或恢复网络时检查。
- 读取失败保留已展示的内容，并沿用现有重连提示；不自动重放领券等写入操作。

## 已有保障，回归测试通过

- 创建奖励使用稳定请求标识；重复领取同一码返回同一份相遇。
- 券消费与增加收藏由数据库事务完成；同一结果重试不重复消耗。
- 学习输入日志保存在本机；服务端成功但响应丢失后可重放且不重复加星。
- 小队保存校验预期旧队伍，拒绝旧设备覆盖新队伍。
- 未打开的精灵球由服务端未确认相遇记录保存，不依赖动画是否完整播放。

## 尚待完成

1. **数据导出和恢复演练**：已新增家长端完整已同步业务数据导出、版本与 SHA-256 校验，并在两份隔离本地数据库中重建比对。需先执行 010 迁移才能上线；真实平台备份恢复与应用内导入仍未完成。详见 [家庭数据导出](family-export.md)。
2. **真实双设备与弱网验收**：本地 SQL 测试为单连接 PGlite，不代表真实并发压测。需验收两设备同时领同一码、领取成功但丢响应、开球过程中退出后重新打开、设备撤销时旧请求返回。
3. **长时间使用观察**：确认 60 秒轮询在真实家庭数据库的延迟及请求量；不是实时推送，弱网时不保证一分钟内更新。
4. **本机存储丢失**：浏览器清理数据会删除尚未同步的学习日志；不能将本机离线日志称为持久云备份。

## 验证

新增 tests/latest-read.test.ts 覆盖请求合并、乱序成功返回、失效后的迟到错误、新请求不被旧请求清理、失败后重试。运行 npm run verify（含 lint、SQL 规则检查及全套测试），并执行类型检查和生产构建。
