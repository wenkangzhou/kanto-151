# 说明和名字朗读

- 使用 Web Speech API，语言 `zh-CN`，语速 0.85。声音由设备提供，不使用动画配音演员的声音。点击才播放，再点停止，切页或进入后台停止。
- 单属性伙伴的说明不提示切换招式；双属性伙伴才提供换招式提示。
- 开球前不提供语音说明，保留 8 秒自动打开逻辑。揭晓伙伴后的播放按钮只朗读伙伴名字。
- 同一时间只朗读一段内容，可独立于背景音乐点播。朗读时暂停背景音乐，结束后按原开关状态恢复。
- 游戏叫声已移除，目前没有接入符合预期的动画叫声。详情大图点击保留无声的打招呼动画。
- 说明音色和离线可用性取决于设备安装的语音。系统缺少语音或播放失败会给出提示。不会朗读家庭奖励原因等私人记录。
