# 拼音教学内容

范围为常用启蒙教学，不是穷举所有声韵组合和带调音节。当前 105 个示例音节、37 个阶段；声母表包含 21 个声母及 y、w，韵母表包含 24 个常用韵母的例音，整体认读表包含 16 个音节。

## 进度与出题

- 阶段下标和音节 ID 为持久化标识。前 8 个阶段及其题池保持原样；后续只追加，不重排已有阶段。
- 阶段题池显式列出音节 ID。给既有声母增添新词，不会悄悄扩大旧阶段题池。
- 后续阶段依次加入 p、f、n、g、k、h、j、q、x、zh、ch、sh、r、z、c、s、y/w，然后练复韵母、前后鼻韵母、整体认读、独立成音节、四声和综合复习。
- 每轮仍为五题；连续两轮各至少四题独立答对后进阶。家长可以固定阶段，设置从下一轮生效。与数学、思维共用每日奖励轮数。
- 已开始的练习保持题目不变。图卡与点读表不触发学习事件、不消耗奖励轮次。

## 读音与图画

- 教学发音使用 `public/audio/pinyin/` 的本地 MP3，系统声音只用于操作反馈；不使用英语字母读音。
- 声母采用呼读音。拼读卡播放声母、介音或韵母后，再单独播放完整音节，不将片段拼接成假音节。
- `gua`、`jia` 等分三张卡；j/q/x 后的 ü 在拼读卡中保留两点，而完整音节遵循省点规则。
- 16 个整体认读音节不拆分。没有准确独立韵母录音的音节只做听音或看图活动，不伪造分音。
- 韵母点读表明确标注“例音”：例如 ong 播放 dōng，不能把 dōng 当成 ong 的独立发音。
- 有清晰图示的音节可做看图题；抽象词只做听音题。看图题的干扰项不采用相同图示。图画用于联想，不要求孩子识字。
- 图卡词语只读目标字，例如“葡萄”听 pú、“蜡烛”听 là；“菇、壳、须、足、林、色”单字展示，避免与词语中其他字混淆。

## 来源与检查

- 普通话录音：[mp3-chinese-pinyin-sound](https://github.com/davinfifield/mp3-chinese-pinyin-sound)，沿用上游 Unlicense；每个下载文件的来源、SHA-256 和时长记录在 `sources.json`。
- 内容编排参考：[人教社拼音教学内容调整说明](https://www.pep.com.cn/bks/xxyw/jzjd/202512/W020251202580887481487.pdf)。本课程为项目自编，非教材的完整复制或官方课程。
- 自动校验音节唯一性、阶段覆盖、三选项合法性、录音完整性、整读不拆分、三拼和 ü 规则、旧进度续做及末阶段边界。
- 新增图卡与听音活动需在浏览器确认，并建议家长陪孩子试用后反馈辨识与发音体验。
