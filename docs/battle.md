# 友好对战（第一版）

入口：我的小队 → 去对战，路由 `/battle`。只从已收集的小队成员选择，敌方从已认识的伙伴中按种族值总和接近程度选出六位候选，开场与重赛随机出现，并在有其他候选时排除上一位对手。双方可以是同种宝可梦。

每场状态只存在 React 内存里，离开即结束，不调用奖励、收藏、小队或库存写入 API。全员每场 100 体力；主动换人占回合，体力为零后的替换不占回合；玩家先出招，敌方轮流使用自己的招式。连续点击由 reducer 按阶段拒绝。24 回合后握手言和，避免无限对战。

这是教学简化规则，不是原作伤害公式：所有招式基础伤害统一 18，乘现有现代双属性相克倍率；不模拟等级、本系加成、能力值、招式原始威力、命中、异常状态或副作用。不会在选择前提示最佳招式。

招式名、属性和可学习关系来自 PokeAPI 官方数据仓库 https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv 。`scripts/sync-battle-moves.py` 将公开 CSV 缓存在 `/tmp/kanto-battle-cache`，输出 `src/data/battle-moves.json`。每只伙伴从简单伤害招式白名单中选最多三种属性，优先本属性；保留来源版本组及学习方式编号。允许历代任一记录，包括技能机器及传授，不表示当前等级已学会。应用运行时不请求外部资料。

无普通伤害招式的伙伴使用“挣扎”；全部招式被对手免疫时也提供此后备招式。按现代规则作为无属性伤害，但第一版不模拟反作用力。UI 不将它标为一般属性。

回归：`node --import tsx --test tests/battle.test.ts`，涵盖连续点击、主动/被动换人、免疫、胜负、回合上限和 151×151 组合不死锁。

儿童可理解性补充：小队入口使用双剑图标；选择伙伴后进入独立 summon 阶段，播放约 1.8 秒投球/现身动画，阶段内拒绝出招和再次换人。首次/被动替换不消耗回合，主动换人现身后再由对手行动。减少动态效果时省略投球轨迹。结束场地替换为获胜宝可梦与奖杯；平局显示双方与握手。小于一倍的伤害提示“效果不显著”，仅零倍提示“没有效果，体力没有减少”。

开场选择己方伙伴之前，可点“换个对手”随机匹配另一位；只有一位候选时隐藏此按钮。奖杯的圆形背景放在独立容器，SVG 保留完整矩形绘制范围，避免圆形裁切杯座。
