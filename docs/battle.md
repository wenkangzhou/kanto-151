# 友好对战

入口：我的小队 → 去对战，路由 `/battle`。只从已收集的小队成员选择，敌方从全部已认识的伙伴中随机选择，一轮候选用完前不重复；候选不止一位时不连续出现相同对手；结束后重赛保留同一对手，方便换位伙伴尝试。双方可以是同种宝可梦。

每场状态只存在 React 内存里，离开即结束，不调用奖励、收藏、小队或库存写入 API。每场为一对一，小队只作为赛前候选；选定后不能换人，出场伙伴体力为零即判负，不由其他小队成员接力。重赛双方恢复各自的最大体力，并重新选择伙伴；比较双方基础速度，速度高的一方每轮先出招；同速在选定伙伴时随机决定一次，整场保持顺序。敌方轮流使用自己的招式。连续点击由 reducer 按阶段拒绝。24 回合后握手言和，避免无限对战。

采用统一等级 50 的教学简化规则，六项种族值均参与：

- 最大体力 = HP 种族值 + 60；其他战斗能力 = 对应种族值 + 5。没有个体值、努力值和性格修正。
- 物理招式使用攻击/防御，特殊招式使用特攻/特防；分类来自 PokeAPI damage_class，按招式本身分类，不按属性猜测。
- 招式威力统一为 40；伤害为 `floor((22 × 40 × 攻击能力 / 防御能力 / 50 + 2) × 属性倍率)`。免疫严格为 0；非免疫至少扣 1 点。双方使用同一公式，扣血下限为 0。
- 速度继续决定先手。血条、损失色段与疲劳颜色均按当前体力/最大体力显示；辅助技术可读取实际值。
- 暂不加入本系加成、原始招式威力、暴击、随机伤害、命中、异常状态或副作用；也不在选招前推荐最佳招式。

招式固定使用 PokeAPI 官方 CSV 中《究极之日／究极之月》（版本组 18）的学习关系；全员 50 级，两个升级位＋两个技能机位。升级位只允许该版本等级 ≤50 的升级攻击招式，学习器位只允许该版本学习器攻击招式，不含教学、遗传。每只伙伴可在小队的“招式”弹层里点槽位替换，选中即保存到家庭数据库，演示模式只写本标签页模拟数据。默认配置、覆盖统计及不足四招的例外见 [battle-learnsets.md](battle-learnsets.md)。

`scripts/sync-battle-moves.py` 输出完整合法池 `src/data/battle-learnsets.json` 和默认招式 `src/data/battle-moves.json`。数据附源文件 SHA-256，运行时不请求外部资料；更新后运行 `npm run sql:rules` 同步数据库校验规则。已部署的规则若需修改，应写新迁移，不能重跑旧迁移。

招式不足时留空，不跨来源补齐；同一招不能重复装备。当前仅支持有正数固定基础威力的攻击招式；所有招式仍统一为一次威力 40 的攻击，不模拟原始命中、PP、多次攻击、反伤等效果。双方使用同一合法池，对手使用默认配招。我方开场复制已保存配置，整场保持不变，重新挑战读取最新配置。进化时保留仍符合新形态、原来源槽位的招式，失效招式按新形态默认配置补齐；不会把升级招式自动挪到学习器位。没有预设时使用新形态默认配置。技能机需在默认开放范围或孩子永久解锁列表内，详见 [学习规则](learning.md)。

对战按钮按两行两列展示，保留属性图标的点击动画。当前全部可选招式的完整出招录音已覆盖；未来新增招式若没有完整句子录音，先播报出招伙伴名字，字幕和属性音效正常；不调用运行时 TTS，也不等待不存在的录音。

无普通伤害招式的伙伴使用“挣扎”；全部招式被对手免疫时暂时用此后备招式替换按钮，不扩成第五招。按现代规则作为无属性伤害，但第一版不模拟反作用力。UI 不将它标为一般属性。

回归：`node --import tsx --test tests/battle.test.ts`，涵盖连续点击、禁止中途换人、仍有健康候选时判负和重赛恢复、免疫、胜负、回合上限和 151×151 组合不死锁。

儿童可理解性补充：小队入口使用双剑图标；选择伙伴后进入独立 summon 阶段，播放约 1.8 秒投球/现身动画，阶段内拒绝出招和再次换人。出场不消耗回合，现身后先展示双方头像、速度和出招顺序，再由先手方行动。减少动态效果时省略投球轨迹。结束场地替换为获胜宝可梦与奖杯；平局显示双方与握手。小于一倍的伤害提示“效果不显著”，仅零倍提示“没有效果，体力没有减少”。

开场选择己方伙伴之前，可点“选对手”打开弹层，查看全部已收集伙伴，按属性筛选；当前对手以边框和文字标记。点选图片直接关闭弹层、切换对手并播报名字，不增加确认步骤。弹层内也可“随机选一位”，沿用全部已收集池的去重随机规则，不受属性筛选限制。关闭或按 Escape 保留原对手；只有一位候选时隐藏入口。iPad 使用居中弹层，手机接近全屏，列表独立滚动。

奖杯的圆形背景放在独立容器，SVG 保留完整矩形绘制范围，避免圆形裁切杯座。

## 对战声音

沿用现有背景音乐开关及设备范围（iPad/桌面）。开启音乐后，进入对战暂停原音乐并播放训练家对战曲；朗读期间对战音乐从 0.12 降到 0.035；退出时恢复原曲原位置。关闭音乐、页面隐藏和卸载均停止声音，不自动打开音乐。

- `public/audio/battle/trainer.mp3`：从用户本地素材目录复制 `1-11. Battle! (Trainer).mp3`。
- `victory.mp3`：`1-12. Victory! (Trainer).mp3` 前 10 秒，最后 2 秒淡出，仅胜利播放。
- `throw.wav`、`hit.wav`：由 `scripts/generate-battle-sounds.py` 生成的短提示音，不是游戏原始音效。投球出场与实际造成伤害时触发；免疫不播放命中声。
- 声音与回合推进独立，媒体播放失败不影响对战。单元测试覆盖静音、朗读降音量、重赛、退出、资源释放与播放拒绝。

赛前己方候选显示可点读的属性，不标注推荐。实际扣血后保留短暂的损失色段再收起，免疫不显示损失动画；减少动态效果时直接更新。结束时从玩家实际造成伤害的招式中保留属性倍率最高的一次，展示招式和目标属性；败北同样展示，没有命中则不虚构回顾。

进入对战页直接匹配对手并选择伙伴，不再重复点击开始。首次点击伙伴为选中，再次点击同一伙伴即投球上场，选择另一位则改变选择；无需底部确认按钮。顶部仅保留返回和更换对手操作，工具栏与其他页面保持一致；选择阶段缩小场地，优先展示六位候选。

## 按压与命中反馈

技能按钮保持平面无阴影；按钮与文字保持固定，接受指令后仅内部属性图标弹起、左右摆动并回弹（480ms），属性底色和名称保持稳定；施放中的按钮保持高亮，其余按钮锁定，连续点击不能重复出招。命中目标在 220ms 内按抗性/普通/克制分别后退 10/17/24px 后短促回震；克制命中同时让场地轻震 160ms，导航保持固定，免疫不播放命中晃动和音效。动画和扣血沿用独立反馈阶段。系统减少动态效果时取消新增位移动画，保留高亮和血条。

支持 `navigator.vibrate` 的设备点击技能时尝试 18ms 轻震；不支持或调用失败时正常继续，不依赖硬件震动。兼容性参考 https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate 。不承诺 iPad 的实体震动反馈。

## 连续挑战与属性音效

结算页的“挑战下一位”保留当前伙伴、随机更换已收集池中的对手；双方恢复满体力，重新计算先后手并清空上一场记录。上场阶段播报新对手名字，不再要求选伙伴。“换伙伴”仍可重新选择，并保留当前对手。

命中音效按招式属性选择 `public/audio/battle/types/` 的本地短 WAV，每段约 480ms，由 `scripts/generate-battle-type-sounds.py` 合成，不调用语音服务。沿用声音开关，语音播报期间降低音效音量；免疫不播放命中音效，切换对战或离开页面会释放正在播放的音效。

## 弱网行为

本场对手与选中伙伴的短语音、投球和属性音效提前准备，最多两个并发请求；已准备的音频保留在有数量上限的会话缓存中，换伙伴或离开页面取消剩余准备请求，不预下载整首背景音乐。语音元素仍在播放调用前同步指定来源，保留 Safari 的点击播放路径。

对战语音加载或缓冲停滞超过 2.5 秒就跳过，回合照常推进；加载时显示“声音加载中…”。正常播放的语音仍等到结束。短音效有单独的 2.5 秒加载期限，开始播放后才计算 700ms 清理时间。声音开关开启后即启用短音效，不依赖背景音乐加载成功。图片元素跨回合保留，避免反复挂载造成闪烁和额外解码。
