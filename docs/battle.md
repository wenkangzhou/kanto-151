# 友好对战（第一版）

入口：我的小队 → 去对战，路由 `/battle`。只从已收集的小队成员选择，敌方从全部已认识的伙伴中随机选择，一轮候选用完前不重复；候选不止一位时不连续出现相同对手；结束后重赛保留同一对手，方便换位伙伴尝试。双方可以是同种宝可梦。

每场状态只存在 React 内存里，离开即结束，不调用奖励、收藏、小队或库存写入 API。每场为一对一，小队只作为赛前候选；选定后不能换人，出场伙伴体力为零即判负，不由其他小队成员接力。重赛双方恢复 100 体力，并重新选择伙伴；比较双方基础速度，速度高的一方每轮先出招；同速在选定伙伴时随机决定一次，整场保持顺序。敌方轮流使用自己的招式。连续点击由 reducer 按阶段拒绝。24 回合后握手言和，避免无限对战。

这是教学简化规则，不是原作伤害公式：所有招式基础伤害统一 18，乘现有现代双属性相克倍率；仅速度参与先手判断，不模拟等级、本系加成、其他能力值、招式原始威力、命中、异常状态或副作用。不会在选择前提示最佳招式。

招式名、属性和可学习关系来自 PokeAPI 官方数据仓库 https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv 。`scripts/sync-battle-moves.py` 将公开 CSV 缓存在 `/tmp/kanto-battle-cache`，输出 `src/data/battle-moves.json`。每只伙伴从简单伤害招式白名单中选最多三种属性，优先本属性；保留来源版本组及学习方式编号。允许历代任一记录，包括技能机器及传授，不表示当前等级已学会。应用运行时不请求外部资料。

无普通伤害招式的伙伴使用“挣扎”；全部招式被对手免疫时也提供此后备招式。按现代规则作为无属性伤害，但第一版不模拟反作用力。UI 不将它标为一般属性。

回归：`node --import tsx --test tests/battle.test.ts`，涵盖连续点击、禁止中途换人、仍有健康候选时判负和重赛恢复、免疫、胜负、回合上限和 151×151 组合不死锁。

儿童可理解性补充：小队入口使用双剑图标；选择伙伴后进入独立 summon 阶段，播放约 1.8 秒投球/现身动画，阶段内拒绝出招和再次换人。出场不消耗回合，现身后先展示双方头像、速度和出招顺序，再由先手方行动。减少动态效果时省略投球轨迹。结束场地替换为获胜宝可梦与奖杯；平局显示双方与握手。小于一倍的伤害提示“效果不显著”，仅零倍提示“没有效果，体力没有减少”。

开场选择己方伙伴之前，可点“换个对手”随机匹配另一位；只有一位候选时隐藏此按钮。奖杯的圆形背景放在独立容器，SVG 保留完整矩形绘制范围，避免圆形裁切杯座。

## 对战声音

沿用现有背景音乐开关及设备范围（iPad/桌面）。开启音乐后，进入对战暂停原音乐并播放训练家对战曲；朗读期间对战音乐从 0.12 降到 0.035；退出时恢复原曲原位置。关闭音乐、页面隐藏和卸载均停止声音，不自动打开音乐。

- `public/audio/battle/trainer.mp3`：从用户本地素材目录复制 `1-11. Battle! (Trainer).mp3`。
- `victory.mp3`：`1-12. Victory! (Trainer).mp3` 前 10 秒，最后 2 秒淡出，仅胜利播放。
- `throw.wav`、`hit.wav`：由 `scripts/generate-battle-sounds.py` 生成的短提示音，不是游戏原始音效。投球出场与实际造成伤害时触发；免疫不播放命中声。
- 声音与回合推进独立，媒体播放失败不影响对战。单元测试覆盖静音、朗读降音量、重赛、退出、资源释放与播放拒绝。

赛前己方候选显示可点读的属性，不标注推荐。实际扣血后保留短暂的损失色段再收起，免疫不显示损失动画；减少动态效果时直接更新。结束时从玩家实际造成伤害的招式中保留属性倍率最高的一次，展示招式和目标属性；败北同样展示，没有命中则不虚构回顾。

进入对战页直接匹配对手并选择伙伴，不再重复点击开始。首次点击伙伴为选中，再次点击同一伙伴即投球上场，选择另一位则改变选择；无需底部确认按钮。顶部仅保留返回和更换对手操作，工具栏与其他页面保持一致；选择阶段缩小场地，优先展示六位候选。
