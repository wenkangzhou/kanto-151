# 城都图鉴预览与关都衔接

## 当前预览

- 直接访问 `/johto/pokedex`。不加入站内导航、首页入口或奖励流程；预览页内可前往丰缘图鉴。
- 按《金／银》的原始城都地区图鉴顺序展示 251 个条目：复用关都的 151 份资料和图片，新增第二世代的 100 份静态资料和本地图片。
- 同时标出地区编号和全国编号。筛选可分别查看关都旧友、第二世代新伙伴，以及直接从关都宝可梦进化而来的城都伙伴。
- 只读展示；不会写入家庭收藏、小队、奖励、练习或对战数据。当前页面可凭地址访问，因此“未开放”指没有站内入口和游戏流程，不是权限控制。

## 正式接入时的建议

1. **一位宝可梦只有一个全国编号和一份收藏记录。** 地区图鉴是编号顺序与可见范围，不是另一份收藏。关都与城都的完成度分别由同一份记录计算。
2. **地区进度单独呈现。** 现有关都 151 的奖励池、章节、小队、练习和对战保持原有边界；城都的章节和奖励在有完整规则后再开放。
3. **进化关系改成跨地区的图谱。** 当前预览识别了 11 条“关都形态 → 城都新形态”的直接关系。第二世代还引入了关都伙伴的幼年形态，需要在正式接入时一并建模，不能只依赖现有的单个 `evolvesFrom` 字段。
4. **以故事而非数据迁移作为入口。** 正式开放时可在关都冒险完成某个明确节点后显示“前往城都”，同时保留直接返回关都的入口；已有收藏自然映射到城都图鉴中的关都条目。

开放前需要确认城都的收集来源、跨地区进化条件、家长奖励范围和家庭数据迁移。预览页暂不承诺这些规则。
