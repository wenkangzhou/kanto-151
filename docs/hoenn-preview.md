# 丰缘图鉴预览与三地衔接

- 直接访问 `/hoenn/pokedex`；不加入首页和正式导航，搜索引擎不收录。可从城都预览页跳转过来。
- 使用《红宝石／蓝宝石》时期的[原始丰缘地区图鉴](https://pokeapi.co/api/v2/pokedex/4/)顺序，共 202 个条目：135 位第三世代新伙伴、47 位关都旧友和 20 位城都旧友。
- 旧伙伴直接复用现有资料和图片，全国编号保持一致，地区编号按丰缘顺序单独显示。135 位新伙伴的资料及图片保存在本地，图片按现有策略缓存。
- 页面只读，不参与收藏、小队、奖励、练习或对战。知道地址的人可以访问，因此它是未公开入口的预览，不是权限限制。
- 点击卡片进入 `/hoenn/pokedex/全国编号` 独立详情页，展示关都、城都、丰缘的地区编号和双向进化关系；同一全国编号只对应一位伙伴。旧的 `?pokemon=全国编号` 地址会转到详情页。
- 详情页沿用关都档案的结构：名字与介绍朗读、大小对比、属性克制互动、完整进化链，以及可展开的六项种族值。预览语音使用设备系统朗读；没有收藏记录时只展示地区足迹，不生成虚构的相遇记录。
- 第三世代每位伙伴都有独立英文介绍，取自已缓存的 PokéAPI 物种资料中的《绿宝石》英文图鉴条目；同步脚本会重建该字段。旧伙伴沿用现有英文翻译或城都英文介绍。

正式接入时继续采用同一个全国编号与收藏记录，分别计算各地完成度。关都、城都与丰缘的章节、获得途径和奖励应各自定义；跨地区进化与幼年形态需要统一的关系图，不能只靠当前单个前一形态字段。开放这些玩法前，再确定收藏来源、进化条件与家庭数据处理规则。
