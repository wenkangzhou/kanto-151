# 学习与技能机（第一阶段）

入口：主导航「去学习」，或从小队招式设置前往学习攒星星。数学已开放；语文、思维、英语展示建设中。学习与其他页面共用每日使用时间，不能用积分兑换时长。

## 配招与兑换

- 四个位置改为 2 个升级 + 2 个技能机；仍使用 USUM 50 级招式池，不加入教学、遗传或未支持的变化招式。
- 每只伙伴有固定的至多两个默认技能机招式，优先本系及擅长的攻击类别，避免与默认升级招式重复。例外伙伴不硬凑四招。
- 默认招式只对该伙伴开放；30 学习星兑换的招式为孩子永久所有，全部合法伙伴共享，包括今后收集或进化的伙伴。装备和替换免费。
- 新迁移把已保存配招从 `[升级1,升级2,升级3,技能机]` 改为 `[升级1,升级2,技能机,空位]`，原技能机永久赠送解锁；展示时补上合法默认招式。
- 学习星为通用余额，不绑定任何招式；攒够后可在小队中任意选择合法技能机兑换，再选择槽位装备。

## 数学规则

每轮五题，0—20 范围内、不出现负数，使用标准减法算式。依次为个位够减、拆十、减十几、混合练习。复习近期未独立完成的一个例题，其余题目随机且本轮不重复。最近两轮在同一阶段各独立答对至少四题后，推荐下一阶段；家长可调整阶段并固定。

首次独立答对 +2 星；重试或提示后完成 +1 星；没有整轮额外奖励，五题最高 10 星，四题独立加一题重试共 9 星。两次答错自动打开点按式拆十辅助，不计独立掌握。孩子点数字拆十，点够指定数量的圆点后才能继续，再将剩余圆点合并；减十几先整组拿走十，再逐个减个位。辅助过程不自动填写或提交原题答案，可重来，关闭后可重新练习。不扣分，不做速度或连胜奖励。答对后保留完整算式约 1.6 秒，显示本题奖励并播放星星飞入口袋的动效，然后自动进入下一题或结算；期间禁止重复提交。自由练习不显示积分动效。答错保留答案，点数字可直接重新填写，也可以删除单个数字修改。

默认每天两轮有积分，家长可设 0—5 轮。轮次在开始时占用，日期按服务器北京时间；未结束的轮次优先续做，跨日继续沿用原来的奖励资格，不再次占新一天名额。额外轮次开始前明确展示自由练习、不增加星星。每日额度重置不清空余额。

题目、尝试、提示、星星、完成记录按操作保存；实际前台练习时长为客户端估计值，不影响积分。未提交题目上的停留不计入统计。家长可看独立完成、提示使用、阶段及最近记录、积分收支。

## 语音与联网

学习部分仅使用设备的 SpeechSynthesis 系统中文语音，通过独立适配器封装；不调用 MiniMax 或产生合成费用。“声音开 / 声音关”同步切换喇叭图标；关闭时立即停止当前播报，自动读题、答题反馈、步骤讲解和手动点读均静音，点读按钮禁用。退出学习停止播报。既有宝可梦语音不重做。

第一阶段在线保存答案后才进入下一题。弱网失败保留原请求，可重试或重新读取，未联网不发可消费积分。冷启动、跨设备读取云端进度；本地演示使用隔离模拟数据。

API 根据设备身份选择孩子，服务端生成题目并判分，不接收客户端余额或积分数。数据库按版本原子更新整个学习手帐，冲突时重新计算；请求编号去重、题目状态与永久解锁共同防止重复发奖／扣费。表启用 RLS，仅服务端角色可读写；设置操作需要家长 PIN 会话。服务端写入再次检查时间锁。

## 上线

依次完成迁移 001—007 后，执行 `supabase/migrations/202609290008_learning.sql`，再部署对应代码。迁移包含学习存储、默认招式规则、旧配招保留和新的配招验证；不要单独部署 2+2 前端而继续使用 3+1 数据库规则。此次开发不自动执行线上 SQL。

`scripts/generate-learning-rules.ts` 从同一套默认招式规则生成 SQL；`npm run sql:check` 校验一致性。积分余额与兑换记录属于真实家庭数据；演示重置不会影响它们。

## 招式兑换与点读

学习小站的兑换入口通往 `/learn/moves`，按已收集伙伴的技能机招式去重展示，可按名字、伙伴或属性筛选。兑换仍为每招式 30 星，永久共享，兑换后选择伙伴及技能机位置装备；默认开放招式可直接装备。复用现有学习与配招接口，无新增 SQL。

兑换卡片、兑换详情、装备位置和招式候选提供独立小喇叭，点读不会兑换或改动配招。招式名称优先使用现有录音，缺少独立名称录音时使用系统中文语音，不产生 MiniMax 合成费用；再次点击停止，切换页面或关闭对应弹层停止播放。对战口令继续使用已有录音。

家长学习手帐分为今日统计、练习安排、练习记录和学习星收支。设备计时使用迁移 009；学习余额与进度仍在家庭设备之间共享。

## 新招式轻引导

小队页提供一次性的「学个新本领」提示，从当前小队选择一个合法、已开放且尚未装备的招式。没有可推荐招式时不显示。点击进入现有配招弹层，首次只显示可以直接装备的新招式；保存成功后提供「去对战试试」。主动选择「全部招式」后才恢复完整候选和原有学习星兑换流程，不新增赠送、不自动装备、不扣星。

提示可关闭，不自动弹窗或播放语音。打开或关闭提示后在该浏览器本地记为已体验，之后不重复；演示使用独立的 sessionStorage。该记录只影响引导，不影响学习进度和奖励，无新增 SQL。

## 弱网学习（2026-10-10）

- 同一页面会话内，学习手账缓存在独立客户端对象，返回路由直接呈现旧数据，并在后台读取新状态。完整刷新首次仍需服务器确认设备与学习记录，不宣称完全离线启动。
- 服务器创建五题及奖励轮次。未完成的一轮在本机立即继续；答题和提示使用同一领域规则立即反馈，不等服务器。
- 每个答题／提示输入在反馈前写入设备本地存储（演示使用 sessionStorage）。正式模式按 childId + deviceId 隔离；更换设备身份不会把旧记录提交到新家庭。
- 8 秒窗口内合并输入，一次最多20条；完成、稍后继续、路由离开、页面隐藏和网络恢复触发同步。不依赖关闭页时请求一定成功：本地日志直到服务器确认后才清除，下次打开从服务器状态重放恢复。
- 服务端只允许批量 answer/hint，逐条重放校验、按原 requestId 去重，复用现有版本 CAS 一次保存。余额、奖励轮次、兑换权限和时间锁仍由服务器决定。不直接信任客户端上报星星。
- 等待同步时显示“记录已保存在本机”，结算不谎称已到账；开启新一轮和兑换前先同步上一轮。普通答题不再查询宝可梦收藏。
- 网络错误后保留日志，不无限自动重试。若另一设备替换了当前练习造成冲突，日志保留并提示重试；如果计时锁已到，需家长重新开启后才能同步，不绕过时间控制。
- 复用 `kanto_device_learning_save`，无需新增 SQL。

## 学习小站视觉（2026-10-10）

学习入口采用伙伴插画主卡 + 星星口袋，延续全站柔和浅绿、奶油色、珊瑚红按钮和圆角边框。陪学伙伴优先选已收集的小队成员，无伙伴时用剪影。未开放科目缩为辅助卡片，统一 Lucide 线条图标；四个数学阶段用编号路线代替 emoji。答题、结算沿用同一伙伴。客户端首次取数及路由加载均使用现有精灵球动画，尊重减少动态效果设置；不增加付费素材、语音或额外数据请求。
