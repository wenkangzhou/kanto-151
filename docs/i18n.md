# 中文与英文

默认中文，右上角切换语言。选择保存在当前设备的 localStorage（kanto-language），不改家庭数据。存储不可用时，本标签页仍可切换。服务端以中文渲染，客户端读取设备偏好后切换英文。

## 文案维护

- src/lib/i18n/en.json：人工翻译的应用文案；不调用外部翻译服务。
- official-names.json：宝可梦、招式、属性等名称。
- zh-catalog.json、templates.json：源码提取的文案和动态模板。
- narrations.json：从人工译文组合的完整介绍，避免长段落依赖模糊的模板匹配。
- 客户端组件使用 useT()；服务端页面使用 LocalizedText。
- 拼音教学字词保留中文，操作提示翻译。家庭名、孩子名、自定义奖励理由保留原文；本地动画预览的示例理由会翻译。
- 包含用户输入的句子用显式模板参数：localize('现在陪{0}学习',[childName])，不要将用户输入交给词典翻译。

新增文案后：
1. 运行 node scripts/i18n/extract.mjs。
2. 人工补齐 en.json，并保持占位符编号。
3. 涉及百科介绍时运行 node --import tsx scripts/i18n/narrations.ts。
4. 运行 npm test、npm run typecheck、npm run lint。
5. 在 Codex 内置浏览器检查中英文、长文字换行及窄屏。

tests/i18n.test.ts 检查提取词条覆盖、占位符、151 个名称、完整介绍和用户输入保留。
tests/i18n-voice.test.ts 检查系统英文朗读、中文录音保留及存储失败行为。
生成介绍可用 node --import tsx scripts/i18n/narrations.ts --check 检查是否需要更新。

## 语音

英文采用设备系统英语语音，不预加载中文录音。中文沿用原有录音。语言切换会停止当前朗读；拼音教学发音继续使用原有中文素材。系统语音的音色和可用性由设备决定。
